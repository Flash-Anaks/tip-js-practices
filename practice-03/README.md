## Организация кода

- `task-service.js` — содержит функции для работы с задачами. Здесь проверяются идентификаторы, названия и приоритеты, выполняются поиск, добавление, изменение статуса, переименование и удаление. Здесь же вычисляется сводка: общее число задач, выполненные задачи, оставшиеся задачи и процент выполнения.
- `task-selectors.js` — выбирает задачи для отображения в зависимости от фильтра: все задачи, задачи в работе или выполненные задачи.
- `task-view.js` — создаёт DOM-элементы карточек и обновляет список задач, сводку и сообщения о пустом списке.
- `main.js` — связывает данные, обработчики событий и отображение. Полный список хранится в переменной `currentTasks`, а текущий фильтр — в `currentFilter`. События обрабатываются функциями `handleTaskListClick()` и `handleFilterClick()`. После успешного изменения данных вызывается `renderApp()`, который обновляет DOM.

Обработчик кликов по задачам установлен на общем элементе списка. Поэтому используется делегирование событий: по `event.target` определяется нажатая кнопка и соответствующая карточка.

## Отладка и клавиатура

В `main.js` обработка кликов по задачам находится в функции `handleTaskListClick()`. Для проверки можно установить точку останова на строке:

```js
const rawId = card.dataset.taskId;
```

На этой строке можно исследовать:

- `event.target` — элемент, на который непосредственно нажали;
- `event.currentTarget` — элемент, на котором зарегистрирован выполняющийся обработчик;
- `card.dataset.taskId` — строковый идентификатор карточки;
- `Number(rawId)` — числовой идентификатор;
- `button.dataset.action` — действие `toggle` или `delete`;
- `result` — результат вызова функции сервиса.

Для изменения статуса вызывается `setTaskCompleted()`, а для удаления — `removeTask()`. Если операция завершается ошибкой, сообщение выводится в `elements.message`.

После успешного изменения вызывается `restoreTaskFocus()`: фокус возвращается на соответствующую кнопку, если она осталась в DOM, иначе — на кнопку текущего фильтра.

Отдельные фактические результаты проверки клавиш Tab, Enter и Space следует внести после ручного запуска этих действий. В браузерных проверках проверка фокуса прошла успешно.
