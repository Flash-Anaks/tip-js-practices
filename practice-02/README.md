## 4. Модель данных и функции

Задача представлена объектом со следующими полями:

- `id` — уникальный идентификатор задачи;
- `title` — название задачи;
- `completed` — признак выполнения (`true` или `false`);
- `priority` — приоритет задачи.

Функции организованы в модуле `src/task-service.js`. Они создают задачи, ищут их, получают списки и статистику, добавляют, переименовывают, отмечают выполненными и удаляют задачи.

При успешном выполнении операции возвращается объект с `ok: true` и результатом операции. При ошибке возвращается объект с `ok: false` и описанием ошибки.

**Почему `id` не равен индексу:** идентификатор сохраняет связь с задачей независимо от её положения в массиве. После удаления элементов индексы оставшихся задач могут измениться, а их `id` остаются прежними.

**Почему `getTaskStats` возвращает число, а не строку с процентом:** числовое значение прогресса можно использовать в дальнейших вычислениях и форматировать отдельно при выводе. В демонстрационном сценарии процент выводится с одним знаком после запятой.

**Какие объекты копируются при изменении задачи:** при переименовании и изменении статуса создаётся новый массив и новый объект для изменяемой задачи с помощью spread-оператора. Объекты остальных задач могут сохранять прежние ссылки. При добавлении и удалении также создаётся новый массив. Поэтому исходный массив не изменяется.
